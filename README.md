# NOCTRA / LUCID-1

Интерактивное исследование вымышленного устройства: процедурная 3D-модель раскрывается через свет, материалы, звук и управляемую прокруткой анимацию.

| Срез | Детали |
|---|---|
| Формат | Восемь связанных web-сцен |
| Состояние | Проверен в WebKit на компьютере и мобильной ширине |
| Технологии | `React` `React Three Fiber` `Three.js` `GSAP` `Web Audio` |
| Публикация | Витрина; исходный код не включён |

## Исследование объекта

Вместо обычной страницы проект ведёт зрителя через восемь сцен: от общего силуэта до послойного разбора устройства. Галерея показывает начало истории, инженерный «взрыв» модели и мобильное досье.

## Визуальная система

- шестислойная процедурная модель;
- PBR-материалы, световые акценты и звук;
- прокрутка как контролируемая временная шкала;
- отдельное техническое досье для мобильного экрана.

## Границы производительности

Предусмотрены WebGL fallback, режим уменьшенной анимации и более лёгкие параметры сцены для устройств с ограниченными ресурсами.
